# DittoBench v5 Phase A — hermetic archetype baseline

Generated by `cmd/v5calibrate` (no key, no Docker): harness archetypes run against
real generated `bench_version` 5 datasets over 24 rotating seeds, each scored
through the real `scorer.AggregateForVersion(v5)` pipeline. This is the offline
half of the plan's 4.10 winnability / statistical-power precheck and the 4.11 ship
gate. Reproduce:

```
go run ./cmd/v5calibrate --seeds 24 --run-size full            # table
go run ./cmd/v5calibrate --seeds 24 --run-size full --json     # machine-readable
```

## Result (24 seeds, run_size full, memory-half composite under the v5 gate)

| archetype          | composite (mean ± SE) | [min, max]   | memory_mean | conv_sanity | % below 0.85 |
|--------------------|-----------------------|--------------|-------------|-------------|--------------|
| honest             | 0.697 ± 0.025         | [0.51, 0.84] | 0.765       | 0.812       | 100%         |
| honest-strong      | 0.758 ± 0.023         | [0.42, 0.92] | 0.809       | 0.875       | 83%          |
| unicorn-router     | 0.292 ± 0.006         | [0.24, 0.36] | 0.584       | 0.000       | 100%         |
| cleartext-parser   | 0.289 ± 0.004         | [0.26, 0.33] | 0.577       | 0.000       | 100%         |

## What this shows

- **The exploit is closed.** The Unicorn-style leak-router and the no-model
  cleartext parser fall below the 0.85 champion line on every seed, and score 0 on
  the conversational-sanity metric.
- **The drop is specific, not a blanket difficulty hike (counter-guard).**
  `honest-strong` ships the SAME strong retrieval stack as `unicorn-router`; the
  only difference is that it grounds conversational turns. It retains 0.94 of its
  memory mean (composite 0.758 vs memory 0.809 — the conversational factor is ~1.0
  for a grounded harness), while the router retains only 0.50 of its memory mean
  (composite 0.292 vs memory 0.584 — the gate halves it, and it also forfeits the
  conversational cases inside the mean). The exploiter is penalized twice; the
  honest harness is not penalized at all.
- **v5 stays winnable.** A conversationally-grounded strong harness reaches up to
  0.92, so the ceiling is non-degenerate.

Pinned in CI by `cmd/v5calibrate/main_test.go` (`TestV5ShipGateMultiSeed`).

## CALIBRATION TRUST WARNING

These per-type competence numbers are **synthetic archetype profiles**, not measured
from a real locked model (same caveat as `cmd/benchcal`). They encode the
qualitative behavior the plan targets. The **on-model** winnability precheck against
the frozen-Qwen reference — real per-type competence AND run-to-run variance, and
the honest-minus-parser gap on the memory half — still requires the model relay and
a harness image (`cmd/calibrate --run-size full` against a running API). That run is
the remaining gate before v5 Phase A enters the on-chain composite; this hermetic
pass covers what can be committed without a key.
